# Secondary learners and outer evaluation execution specification

Recorded 7 October 2026 after the 84 registered inner XGBoost fits and before any new outer model predictions. User instruction: “lets proceed with the experiments.” This implements the approved `revision_v0.2` F29 protocol and does not amend the frozen IEEE Access study.

The fixed five-schema panel is F13, F6_PRIMITIVES, S13 (`LOCO_active_duration_minutes`), F29 and Splus (`FAM_actions`). The latter two subset choices follow the registered XGBoost inner selection rule. Seeds are 42, 52 and 62. Random Forest and attention-linear each receive 15 inner calibration fits and 15 outer refits. Together with 84 completed inner XGBoost fits and 30 outer XGBoost fits, the campaign contains 174 fits. Optional history remains disabled.

Exact learner parameters, runtime versions, source hashes, inputs and tests are recorded in the secondary executable manifest before fitting. Random Forest retains 200 trees, depth 20, minimum leaf size 2, balanced_subsample and max_features=1.0, with four threads. Its large cost is accepted as part of the approved recipe; no outcome-dependent or runtime-dependent parameter substitution is allowed. Attention-linear uses the approved randomly initialized bidirectional LSTM/attention recipe, CUDA float32 without AMP or TF32, deterministic algorithms, Adam at 0.001, batch size 1,024, at most 15 epochs and patience four. Equal INNER_SELECT AP retains the earlier checkpoint. Each outer schema uses the upward-rounded median of its three best inner epochs, constrained to 1–15, without outer stopping.

All 30 secondary inner fits must complete and their artifacts and operating points must verify before any outer XGBoost or secondary predictions. Inner thresholds use all unique float64 scores plus positive infinity, maximize F1 and break ties toward the larger threshold. Outer thresholded results are labeled TRANSPORTED_THRESHOLD. Feature definitions, chosen schemas and all analysis code are frozen in executable manifests before outer predictions. Full-TRAIN daily preprocessing uses only TRAIN and retains the indicator set fixed from INNER_TRAIN. Validation parity extraction is separate from inference.

XGBoost F29 minus F13 remains the sole primary contrast. Improvement requires an observed mean seed AP gain of at least 0.005 and a paired 95% user-cluster percentile interval above zero. S13 noninferiority uses the prespecified 0.005 margin and one-sided 95% lower bound. Other comparisons, including learner transfer and source withdrawals, are exploratory. Use 2,000 attempted paired bootstrap draws, seed 42, cluster multiplicity, per-seed AP differences averaged within each draw, linear percentiles, and at least 1,900 valid draws. Report all 20 nonoverlapping start offsets. Validation is historically reused and supports retrospective comparisons only.

Cache reuse requires matching run identity and artifact hashes. Partial or failed fits are retained and are not automatically refitted. Jobs use the single-writer coordination lock and run sequentially. Model fit/inference time and process RSS are measured; attention also records peak PyTorch CUDA allocation, which is not whole-device peak memory. Unmeasured hardware costs remain explicitly unmeasured. TEST tensors and TEST feature/label aggregation are excluded; raw chronological boundary framing is disclosed in the validation preflight. No Cursor review is claimed.
