# Repository Scope

This private repository is being prepared as the reproducibility package for the IEEE Access paper.

## Included

- Dated manuscript snapshots
- Reviewed experiment protocols
- Result summaries and provenance manifests
- Reproduction instructions
- Reviewed code supporting the reported paper experiments

## Not included

- Raw or processed CERT datasets
- CERT answer files or insider identifiers
- Model checkpoints and large prediction files
- Unreviewed exploratory experiments
- Final LaTeX source until the manuscript is frozen

## Research coverage

- Objective 1 / Chapter 3 Phase 1: chronological data preparation
- Objective 2 / Chapter 3 Phase 2: sequence–ensemble modelling and evaluation
- Objective 3 / Chapter 3 Phase 3: explanation and robustness analysis
