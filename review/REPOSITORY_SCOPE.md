# Repository Scope

This private repository is the paper-support and reproducibility repository for
the IEEE Access manuscript. It is not a general PhD companion repository.

The repository name retains the original `teacher-anchored-insider-threat-detection`
wording for continuity, although the revised manuscript now uses
"Teacher-Guided".

## Included

- Dated manuscript snapshots and the frozen LaTeX source of those snapshots
- Reviewed experiment protocols
- Result summaries and provenance manifests
- Reproduction instructions
- Reviewed code supporting the reported paper experiments

## Not included

- Raw or processed CERT datasets
- CERT answer files or insider identifiers
- Model checkpoints and large prediction files
- Unreviewed exploratory experiments

## Evidence streams in the current manuscript

- CERT r4.2 — development evidence
- CERT r5.2 — historical guarded-reference evidence and final train/validation
  evidence
- CERT r6.1 — one-pass cross-release evidence

CERT r6.2 is outside the current manuscript and is retained only as historical
material.

## Research coverage

- Objective 1: chronological data preparation
- Objective 2: sequence–ensemble modelling and evaluation
- Objective 3: explanation and robustness analysis
