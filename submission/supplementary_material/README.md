# Supplementary Material

Status: IN PROGRESS

Only verified paper-facing material belongs here. Candidate contents include:

- extended verified result tables;
- seed-level results omitted from the manuscript for space;
- additional sensitivity analyses;
- producing configurations and manifests;
- figure source data;
- reproducibility instructions;
- bounded explanation examples;
- supplementary methods required to understand the reported evidence.

Raw CERT data, unrestricted user-level records, temporary outputs and unrelated
experimental work must not be included.
