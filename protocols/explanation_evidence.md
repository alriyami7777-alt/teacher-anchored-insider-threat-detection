# Protocol: Explanation Evidence

**Aim:** Assess whether model explanations provide faithful evidence for analyst interpretation.


## Components

- Temporal attention extraction.
- Attention perturbation and top-versus-random comparison.
- Native ODST route, tree, and leaf contributions.
- Reference-centred contribution analysis.
- Multi-seed confirmation.
- Sensitivity analysis retaining negative raw-ranking findings.

## Reporting

Report the exact reference, ranking rule, value of k, cohort, repetitions, seed coverage, and comparability limits.
